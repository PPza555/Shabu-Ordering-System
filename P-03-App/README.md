## วิธีการเริ่มใช้งาน (Getting Started)

มีสองวิธีหลักในการรันโปรเจกต์นี้ เราแนะนำให้ใช้วิธีที่ 1 เพื่อความง่ายและรวดเร็ว

### วิธีที่ 1: การใช้สคริปต์เริ่มต้น (แนะนำ)

วิธีนี้จะทำการติดตั้ง Dependencies ที่จำเป็นและเริ่มรันเซิร์ฟเวอร์โดยอัตโนมัติ

1.  **เปิด Command Prompt** หรือ Terminal ภายในโฟลเดอร์โปรเจกต์
2.  **พิมพ์คำสั่งต่อไปนี้:**

    ```bash
    start.bat
    ```

    หรือคุณสามารถ **ดับเบิลคลิกไฟล์ `start.bat`** ได้เลย

ระบบจะติดตั้ง Dependencies และเริ่มรันเซิร์ฟเวอร์โดยอัตโนมัติ

### วิธีที่ 2: การใช้คำสั่ง NPM โดยตรง

หากคุณไม่ต้องการใช้ไฟล์ `.bat` คุณสามารถรันคำสั่งโดยตรงผ่าน NPM ได้

***ข้อกำหนดเบื้องต้น:** คุณต้องติดตั้ง [Node.js](https://nodejs.org/) ก่อน*

1.  **ติดตั้ง Dependencies:**

    ```bash
    npm install
    ```

2.  **เริ่มรันเซิร์ฟเวอร์:**

    ```bash
    npm start
    ```

## URL สำหรับการทดสอบระบบ

เมื่อเซิร์ฟเวอร์ทำงานอยู่ที่ `http://localhost:3000` แล้ว คุณสามารถเข้าถึงส่วนต่างๆ ของระบบได้ตาม URL ต่อไปนี้:

### ฝั่งลูกค้า (Customers)

ส่วนติดต่อลูกค้าจะถูกเข้าถึงโดยการระบุหมายเลขโต๊ะ (`table_id`) ใน URL

**รูปแบบ URL:**
`http://localhost:3000/?table_id={หมายเลขโต๊ะ}`

| หมายเลขโต๊ะ | ตัวอย่าง URL |
| :----------: | :------------------------------------------- |
| **1** | `http://localhost:3000/?table_id=1`          |
| **2** | `http://localhost:3000/?table_id=2`          |
| **3** | `http://localhost:3000/?table_id=3`          |
| **(ไม่ระบุ)** | `http://localhost:3000/?table_id=0` (ระบบจะกำหนดเป็นโต๊ะ 0) |

#### หมายเหตุสำคัญเกี่ยวกับการเปลี่ยนหมายเลขโต๊ะ

เมื่อหมายเลขโต๊ะถูกกำหนดแล้ว จะไม่สามารถเปลี่ยนได้โดยตรงผ่าน Address Bar

หากต้องการเปลี่ยนหมายเลขโต๊ะสำหรับการทดสอบ คุณจะต้องเข้าไปแก้ไขใน **Local Storage** ของเบราว์เซอร์:

1.  เปิด **Developer Tools** (โดยปกติคือการกด **F12** หรือคลิกขวาแล้วเลือก **Inspect**).
2.  ไปที่แท็บ **Application**.
3.  เลือก **Storage** -> **Local Storage** -> `http://localhost:3000`.
4.  หาคีย์ที่เกี่ยวข้องกับหมายเลขโต๊ะและเปลี่ยนค่า **Value** เป็นหมายเลขโต๊ะที่คุณต้องการ

### ฝั่งหลังร้าน (Back Office)

| บทบาท | คำอธิบาย | URL |
| :--- | :--- | :--------------------------------- |
| **Cashier** (พนักงานแคชเชียร์) | จัดการการชำระเงินและออกบิล | `http://localhost:3000/cashier` |
| **Orders** (ครัว) | ดูรายการคำสั่งซื้อสำหรับเตรียมอาหาร | `http://localhost:3000/orders` |
| **Serve** (พนักงานเสิร์ฟ) | ติดตามสถานะการเสิร์ฟอาหาร | `http://localhost:3000/serve` |
